# Frankenstudio 🧟

**One idea in. One finished, publishable piece out.**

Frankenstudio stitches together parts that were never built to work together — a planner LLM, a writer, a code-drawn illustrator, a headless-browser researcher, a second-vendor critic and ffmpeg — into one app. Type an idea or paste a link; get back a long-image article and a 30-second vertical video.

Built for solo creators with no team. It never posts anywhere: you get downloads and copyable text, and you press publish yourself.
